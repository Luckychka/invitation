# Сайт-приглашение

Одностраничный сайт: Лиза проходит короткий опросник, выбирает место, день и время,
а в конце жмёт «Я согласна» — и открывается Telegram с твоим чатом и уже готовым текстом ответа.

## Файлы

| Файл | Что внутри |
|---|---|
| `index.html` | разметка страницы |
| `styles.css` | дизайн, адаптив, анимации |
| `script.js` | вопросы, логика, отправка в Telegram |

Никаких сборщиков, библиотек и сервера — это статика, работает «как есть».

## Как поменять тексты/варианты

Всё настраивается в начале `script.js`:

```js
const CONFIG = {
  name: 'Лиза',          // имя девушки
  telegram: 'Belo0yo'   // твой юзернейм в Telegram (без @)
};
```

Дальше в том же файле:

- `MOODS` — вопрос про настроение и варианты ответа;
- `PLACES` — кафе / кино / прогулка: заголовок вопроса и варианты;
- `PLACES[key].options` — подварианты (что именно заказываем, какой фильм и т.д.);
- `TIMES` — часы, которые предлагаются (по умолчанию с 17:00 до 22:00);
- `buildMessage()` — текст сообщения, который уходит тебе в Telegram.

Добавить свой вариант времени достаточно одной строки в `TIMES`:

```js
const TIMES = ['17:00', '18:00', '19:00', '20:00', '21:00', '22:00', '23:30'];
```

## Как это работает

1. Шаг 1 — настроение.
2. Шаг 2 — куда идём: кафе / кино / прогулка.
3. Шаг 3 — детали выбранного места.
4. Шаг 4 — день: сегодня / завтра / послезавтра / любая дата вручную.
5. Шаг 5 — время: чипсы 17:00–22:00 или любое время вручную.
6. Шаг 6 — итоговая сводка и кнопка «Я согласна».

Кнопка открывает `https://t.me/<твой_юзернейм>?text=<текст>` и параллельно копирует текст
в буфер обмена (Telegram Desktop не подставляет текст сам — на телефоне подставится).

## Как залить на хостинг

Подойдёт любой статический хостинг, папку загружаешь целиком:

- **GitHub Pages** — закинь файлы в репозиторий, Settings → Pages → выбери ветку;
- **Netlify** — перетащи папку на [app.netlify.com/drop](https://app.netlify.com/drop);
- **Vercel** — `npx vercel --prod` в папке с сайтом;
- **Timeweb / Beget / любой shared-хостинг** — файлы в папку `public_html`.

Сайт полностью статичный: бэкенд, домен и база данных не нужны.

## Проверка локально

Просто открой `index.html` двойным кликом, либо:

```
python -m http.server 8000
```

и зайди на `http://localhost:8000`.

> На телефоне проверяй именно по ссылке (например, через Netlify) — `file://` и `localhost`
> с телефона недоступны, а в Telegram переход с мобильного работает лучше всего.
